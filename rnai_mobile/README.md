# Rnai Mobile App (Flutter Native)

แอปพลิเคชันมือถือแบบ Native สำหรับระบบ **Rnai AI** และ **Rnai Student Edition** พัฒนาด้วย Flutter รองรับทั้ง iOS และ Android

---

## 📱 จุดเด่นและฟังก์ชันหลัก

1. **ระบบเลือกเป้าหมาย & ความจำนง (Intent Matrix)**:
   - เลือกระหว่าง 6 ความจำนง: 📚 สรุป & วิเคราะห์, 🎓 บทเรียน & การสอน, 💻 เขียนโค้ด, 💡 วางแผน, 🔍 ค้นคว้า, 💬 สนทนาทั่วไป
   - สร้างโฟลเดอร์สำหรับจัดเก็บโปรเจกต์แยกตามหัวข้อ
   - สร้างและอัปเดตไฟล์ `Memory.md` อัตโนมัติทุกครั้งที่มีการสนทนา

2. **ระบบพิมพ์ด้วยเสียงพูด (Speech-to-Text)**:
   - แปลงเสียงพูดภาษาไทยและภาษาอังกฤษเป็นข้อความในกล่องแชทแบบเรียลไทม์
   - แอนิเมชันปุ่มไมโครโฟนกะพริบแจ้งเตือนสถานะการบันทึกเสียง

3. **Memory.md Live Sheet**:
   - หน้าต่าง Bottom Sheet สำหรับตรวจสอบบันทึกความจำและบริบทของ AI ประจำโครงการ
   - ปุ่มกดคัดลอก และรีเฟรชข้อมูล

4. **Document Hub (คลังเอกสาร)**:
   - อัปโหลดเอกสารจากมือถือ (PDF, Word, Text, Code) เข้าสู่เซิร์ฟเวอร์
   - ดูตัวอย่างเนื้อหาของเอกสาร และกดแทรกเข้าสู่ห้องแชทได้ทันที

5. **ตั้งค่าการเชื่อมต่อ (Settings)**:
   - กำหนด Server IP / Port (เช่น `http://192.168.1.xxx:8765`)
   - สลับโหมดการทำงานระหว่าง **Rnai Standard** และ **Student Edition**
   - ปุ่มทดสอบการเชื่อมต่อเซิร์ฟเวอร์แบบเรียลไทม์

## 🚀 วิธีเปิดใช้งาน

### 1. เปิดเซิร์ฟเวอร์ Rnai Backend บนคอมพิวเตอร์
เปิด Terminal ในเครื่อง Mac/PC:
```bash
rnai ui
```
*(เซิร์ฟเวอร์จะเปิดทำงานที่พอร์ต 8765)*

### 2. รันแอปพลิเคชัน Flutter

#### ก. รันบน iPhone จริงที่เชื่อมต่อ (เช่น "Rnai Bro’s iPhone"):
```bash
cd rnai_mobile
flutter run -d "00008140-000630363AF1801C"
```

#### ข. รันบน iOS Simulator:
```bash
cd rnai_mobile
flutter run -d apple_ios_simulator
```

#### ค. รันบน Android Emulator (Pixel):
```bash
cd rnai_mobile
flutter run -d Pixel_10_Pro_XL
```

#### ง. รันบน macOS Desktop (ทดสอบบนเครื่องทันที):
```bash
cd rnai_mobile
flutter run -d macos
```

## 🌐 การกำหนด IP สำหรับการเชื่อมต่อ

| สภาพแวดล้อมที่รัน | URL เซิร์ฟเวอร์ที่ต้องตั้งค่าใน Settings |
|---|---|
| **iOS Simulator** | `http://127.0.0.1:8765` |
| **Android Emulator** | `http://10.0.2.2:8765` |
| **มือถือจริง (iPhone / Android)** | `http://<IP ของ Mac ใน Wi-Fi>:8765` (เช่น `http://192.168.1.50:8765`) |
| **โหมด Student Edition** | พอร์ต `8766` หรือเปิดสวิตช์ในเมนู Settings |
